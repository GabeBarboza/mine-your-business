# ADR 0001 - Identidade original durante o desenvolvimento

- Status: aceito para desenvolvimento
- Data: 2026-08-28

## Contexto

O projeto e inspirado nas regras de Saboteur, mas nao ha registro de uma licenca para usar a marca, os textos ou os assets do produto comercial.

## Decisao

Usar o titulo original `MINE YOUR BUSINESS`, o subtitulo `Just do your job. Probably.`, textos, codigo, ilustracoes, audio e interface originais. O manual fornecido e uma referencia funcional. Qualquer mudanca para um porte oficial exige licenca documentada e uma revisao deste ADR.

## Consequencias

- Nenhum asset ou texto do manual entra no jogo.
- IDs tecnicos descrevem conceitos genericos, sem depender da marca Saboteur.
- Arte provisoria tambem deve ser original ou possuir licenca compativel.
